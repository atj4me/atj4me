### Open source

#### ddev-sql-sync
[ddev-sql-sync](https://github.com/atj4me/ddev-sql-sync) — a DDEV add-on that syncs a database from a remote host into a local DDEV project with one command: `ddev sql-sync @prod @self`. I built it because pulling a database down by hand was the slow part of every project.

#### ddev-tailscale-router
[ddev-tailscale-router](https://github.com/atj4me/ddev-tailscale-router) — a DDEV add-on that shares local projects over Tailscale, so work in progress can be opened on a phone or shown to someone without deploying anything first.
